# bfm-update

Programm-Updates fuer den STUAG Bauformular Manager. Die Datei update.txt ist mit dem Herstellerschluessel signiert und enthaelt Version, Download-Adresse und SHA-256-Pruefsumme des Setups; das Programm installiert nur Setups mit passender Pruefsumme. Das Programm ist lizenzpflichtig.
